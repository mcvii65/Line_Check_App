# Line Check

## Student Name
Michael Vaccaro II

## App Description
Line Check is a basketball analytics app that will help users compare their
research-based win probability for an NBA game with the probability implied by
the sportsbook's odds. It will highlight where a user's analysis and the market
disagree, helping users make more informed decisions without guaranteeing picks.

## Intended Users
Line Check is intended for casual-to-serious NBA fans and bettors who want
data-driven reasoning behind their bets, as well as students and analysts
interested in sports analytics.

## Planned Features
- Convert betting odds to implied probability and calculate expected value.
- Compare team form and win streaks while accounting for opponent strength.
- Summarize injuries and their potential impact on a game.
- Account for rest and schedule factors such as back-to-backs and travel.
- Track bets, return on investment, and bankroll over time.
